# Decisions

**Inbox.** I used the Express and React scaffold. MongoDB stores conversations, inbound messages, and replies with workspace-scoped unique indexes. Messages are ordered by provider timestamp with message ID as the tie-breaker. Conversation pages use activity time and contact as the cursor. A conditional update gives a conversation one assignee. Closing a conversation leaves its owner and message history in place, and agents can reopen it explicitly.

**Provider.** The webhook verifies a timestamped HMAC against the raw body before parsing. The server records each reply before acknowledging it and reuses the same Pigeon idempotency key across retries. A MongoDB lease coordinates pacing and Retry-After for each workspace across workers. If a worker dies, another can pick up the reply when the reservation expires. A late sent update leaves a terminal delivery status intact.

**Access and live updates.** Login uses OIDC authorization code with S256 PKCE, state, nonce, and signature validation. MongoDB stores hashed session identifiers with an expiry. Both HTTP and WebSocket access require workspace membership. Inbox writes record pending changes alongside their data. A worker publishes them to a durable feed, and clients can reconnect with their last sequence.

**Billing.** The browser sends test card details directly to Paybox and forwards only the resulting token to Switchboard. Workspace admins can subscribe and change seats. A MongoDB lease serializes billing mutations per workspace, and Paybox idempotency keys cover customer creation, token attachment, and subscription changes. Signed webhooks reread the current subscription. Reply gating and the billing screen also read current provider state. Past-due workspaces can send while Paybox retries. A canceled workspace can read its inbox and can send again after resubscribing. Seat reductions apply immediately without removing anyone's access and credit the next invoice. Bank approval opens in a new tab while the billing page refreshes its state.

**Limits.** The event feed has no retention policy, and each open socket polls MongoDB. Default secrets and the mock login are for local development. Encrypted notes and Elasticsearch search were left out. The full public check passed 75/75 on native Linux. An earlier Windows bind-mounted run exceeded Pigeon's retry window during restart and lost inbound messages. The native run recovered every message.
